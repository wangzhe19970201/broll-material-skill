# Broll取材skill

从一个概念、一句话、链接、截图、视频或口播稿出发，寻找可核验的原始依据，同时收集演示画面、B-roll 和社交平台上的有趣素材。

核心要求是来源可追溯、引用不超出证据、画面可用。每条重要论据保留来源地址与原文位置；素材保留作者、语境、来源关系及建议用途。

## 安装位置

将本仓库的技能文件放入所用客户端支持的技能目录，文件夹建议命名为 `video-evidence-broll`。可以按需要选择：

- 项目级：`<项目技能根目录>/video-evidence-broll/`，供相应项目使用。
- 用户级：`<用户技能根目录>/video-evidence-broll/`，供当前用户的多个项目使用。

尖括号内容是占位符，应替换为客户端实际配置的目录。以客户端的技能设置、可用技能清单及作用域规则为准，不需要使用本项目作者的用户名或盘符。

安装后，入口应位于所选技能根目录下的 `video-evidence-broll/SKILL.md`；同时保留 `references/` 和 `agents/` 的相对位置。让客户端按其支持的方式重新发现技能，确认清单中出现本 Skill，再调用。

## 依赖

- **Agent Reach**：用于联网渠道发现与访问。技能标识是 `agent-reach`；可以安装在宿主支持的项目级或用户级技能目录，不要求与本 Skill 放在同一个根目录。本 Skill 优先按宿主技能清单找到它，找不到再检查相应作用域。
- **实际访问能力**：按 Agent Reach 的说明配置本次要使用的渠道。安装了技能说明文件，不代表对应 CLI、登录态或浏览器已经可用。
- **截图与媒体工具**：按具体任务使用宿主可用工具；下载、截图、抽帧或文档处理需要哪些工具，执行时再检查。`windows-shell-adapter` 仅作为已有 Windows 环境的辅助技能，不要求所有用户安装。

完整的依赖查找顺序、多个副本的处理及缺失时的行为见 [Skill 入口](SKILL.md#依赖与环境)。技能采用平台无关的路径规则；具体渠道和工具仍需在使用者自己的环境中验证。

## 使用示例

支持按技能标识调用的客户端可使用 `$video-evidence-broll`，也可以在任务中明确要求使用“Broll取材skill”。

> 用 Broll取材skill 帮我调研“汽车负压吸附”，找到官方说明和技术依据，再收集相关演示与 X 上有趣的素材，保留来源并下载到本项目的素材目录。

> 用 Broll取材skill 查一下这张截图来自哪个原始视频，找到清晰版本，标明原始地址和时间码。

> 用 Broll取材skill 核实这段稿子的关键说法，先交付来源和可用表述，暂时不下载素材。

输入只有概念时，先确定对象与研究问题，无须先准备稿件。用户只要求核实或分析时，不自动批量下载。

## 交付内容

- 论据：原始地址、发布者及身份依据、原文定位、核验状态、可支持的表述与限制。
- 素材：原帖与原始画面地址、作者与转载关系、内容性质、看点与使用建议。
- 用户要求下载时：清晰可用的本地文件，以及串起论据、来源和素材的索引，放进同一个主题总目录。

官方声明、专利方案、实测结果和个人评价分别标注；截图和下载文件的数量不作为真实性或完成度的证明。

## 发布与凭据

仓库只包含技能规则、说明和通用模板。Agent Reach 及其他工具的本地配置、API Key、Token、Cookie、登录状态、环境变量文件和账号资料不随本 Skill 分发，由使用者在自己的环境中配置。

分享调研产物或示例前，检查链接中的访问令牌、截图中的账号信息及日志中的认证信息；原始来源地址优先使用无需携带私人凭据的公开链接。检查记录只写问题类型和位置，不复述秘密值。
